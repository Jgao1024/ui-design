# 真机截图：复刻已有 App 的参考稿

复刻一个已有 App（例如豆包）之前，先从真机截一套参考图，再照着画原型。
不要凭印象画。

## 结论（直接照做）

1. iPhone 用线连 Mac，解锁，开着开发者模式。
2. 切到要截的外观（整套截完再切另一种，不要截一张切一次）：
   `xcrun devicectl device settings appearance --device <udid> --mode dark`
3. 开连拍，人在手机上操作，脚本每 3 秒截一张，和上一张一样就丢掉：
   `./design/device-watch.sh doubao dark`（Ctrl-C 停）
   产物在 `design/.ref/<app>/device/<dark|light>/raw/<时分秒>.png`，挑好的改成清单里的文件名放到上一级。
   只截一张用 `./design/device-shot.sh doubao dark 01-home`。
4. 深色全部截完，`--mode light` 再按同样顺序截一遍。
5. 截完把手机外观恢复成原来的设置。

去重规则：裁掉顶部 180 px 状态栏（时间、电量总在变），缩成 54 x 120 灰度图，和上一张保留的比，
平均像素差小于 `THRESHOLD`（默认 1.5，范围 0-255）算重复。实测：同一张图差 0，不同页面差 100 以上。

`design/.ref/` 已加入 `.gitignore`：截图是第三方 App 的界面，只在本机参考，不提交。

## 走过的路（为什么是这个方案）

| 尝试 | 结果 |
|---|---|
| App Store 截图（iTunes lookup API） | 能拿到 9 张，但都是营销图，没有首页、侧边栏等日常界面。只作补充，存在 `design/.ref/doubao/appstore/` |
| iOS 模拟器 | 不行：App Store 包只能装在真机上，模拟器装不了 |
| Android 模拟器 | 能装 APK，但界面和 iOS 版不同，不采用 |
| 真机 + `devicectl device capture screenshot` | 可行。Xcode 自带（DeviceHub 用的同一套 CoreDevice），不用装第三方工具，不用代理 |
| `devicectl device simulate statusBar preset screenshot`（固定 9:41） | 真机不支持，只能用于模拟器。截图里的时间和电量就是当时的真实值 |

## 常用命令

```bash
xcrun devicectl list devices                                   # 找 udid，看是否 paired
xcrun devicectl device info apps --device <udid> --include-all-apps | grep 豆包   # 查 App 是否已装、版本号
xcrun devicectl device process launch --device <udid> --terminate-existing com.bot.doubao   # 冷启动 App
xcrun devicectl device settings appearance --device <udid> --mode light|dark      # 切深浅色
```

- devicectl 不能点击屏幕，页面跳转要人在手机上点；所以用 `device-watch.sh` 连拍，人来点。
- 读不到当前外观设置：先截一张图判断原来是深色还是浅色，截完恢复。
